# PRD: HearthDeck Hub Public Beta

상태: Draft for validation  
오너: Product / UX / Engineering  
기준일: 2026-06-07

## 문제 정의

하스스톤 덱 정보는 통계 사이트, 게시판, 영상, 대회 기사에 흩어져 있다. 유저는
현재 패치 유효성, 성적의 근거, 본인 적합성, 운영법과 정확한 코드를 별도로
확인해야 한다. 이 마찰은 좋은 덱을 발견해도 실제 게임에서 시험하기 전에
이탈하게 만든다.

## 목표

- 현재 패치 덱을 빠르게 발견하게 한다.
- 근거와 적합성을 과장 없이 판단하게 한다.
- 발견 후 90초 안에 코드를 복사해 게임으로 이동하게 한다.
- 유저 덱과 외부 최신 덱을 검증 가능한 형식으로 축적한다.
- 덱 단위 추천·저장·토론으로 재방문 동기를 만든다.

## 비목표

- 최대 규모의 매치 통계 플랫폼
- 범용 하스스톤 자유 게시판
- 모든 게임 모드와 언어 지원
- 자동 생성 가이드나 추정 승률
- 검토 없는 외부 덱 자동 게시

## 대상 사용자

1. 복귀·초보 정규전 유저
2. 새 덱을 시험하는 일반 등급전 유저
3. 대회·랭커 덱을 추적하는 경쟁 유저
4. 덱과 운영법을 공유하는 기여자
5. 외부 덱을 검증·큐레이션하는 운영자

## 핵심 기능

### 발견

- 홈 큐레이션
- 검색, 직업·태그·출처·근거·패치 필터
- 추천·복사·최신·트렌딩 정렬

### 판단과 복사

- 현재·이전 패치 표시
- 근거 상태와 원문 링크
- 추천 대상, 난이도, 장점·약점
- 운영법, 멀리건, 카드 선택, 카드 목록
- 데스크톱·모바일 한 번 복사

### 기여

- 코드 검증
- 구조화된 가이드 작성
- 승·패와 출처 입력
- 초안 저장, 수정, 게시

### 최신 덱 운영

- 허용 소스 수집
- 코드·카드·패치 검증
- 중복 및 교차 출처 클러스터
- 관리자 승인·반려·기존 덱 연결
- 공식 이벤트 기사 검증과 운영자 매니페스트

### 커뮤니티

- 추천
- 즐겨찾기
- 단일 레벨 댓글
- 신고와 운영자 숨김

## 사용자 시나리오

### 초보 덱 선택

유저는 홈에서 초보 추천을 선택하고 쉬움·현재 패치 덱을 비교한다. 상세에서
추천 대상과 멀리건을 읽고 출처 상태를 확인한 뒤 코드를 복사한다.

### 대회 덱 발견

경쟁 유저는 출처를 대회 덱으로 필터링하고 트렌딩 순으로 본다. 상세에서 공식
이벤트 원문과 패치를 확인하고 코드를 복사한다.

### 내 덱 공유

로그인한 유저는 코드를 붙여넣어 카드 구성을 검증한다. 운영법과 멀리건,
출처·전적을 입력하고 초안으로 검토한 뒤 게시한다.

### 외부 후보 큐레이션

운영자는 코드 검증이 끝난 후보를 원문과 대조한다. 같은 코드의 공개 덱이 있으면
연결하고, 없으면 큐레이션 초안을 만들어 가이드를 완성한 뒤 게시한다.

## 성공 지표

### 북극성 지표

주간 **신뢰 덱 복사 사용자 수**: 현재 패치이며 출처 연결 또는 운영진 확인
근거를 가진 덱의 코드를 주 1회 이상 복사한 고유 사용자 수.

이 지표는 단순 페이지뷰가 아니라 제품이 약속한 “믿고 게임으로 이동”을 측정한다.

### 활성화

- 방문 세션 중 덱 상세 진입률
- 상세 진입 후 코드 복사율
- 첫 방문부터 첫 복사까지 중앙값
- 검색·필터 후 결과 클릭률

초기 목표:

- 5명 테스트 중 4명 이상 과업 성공
- 첫 복사 중앙값 90초 이하
- 상세 진입 후 복사율 20% 이상

수치는 초기 베타의 학습 기준이며 실제 베이스라인 후 재설정한다.

### 공급과 품질

- 주간 신규 공개 덱 수
- 현재 패치 덱 비율
- 출처 연결·운영진 확인 덱 비율
- 등록 시작 대비 초안 저장·게시 완료율
- 검토 후보의 처리 시간과 승인율
- 유효하지 않은 코드 공개 건수: 0

### 유지와 커뮤니티

- 7일 재방문율
- 복사 후 즐겨찾기 비율
- 덱당 유의미 댓글 수
- 신고율과 처리 시간

### 가드레일

- 이전 패치 덱을 현재 덱으로 잘못 표시한 건수
- 근거 없는 승률 노출 건수
- 복사 API 오류가 실제 클립보드 복사를 막은 건수
- 스팸 댓글·신고 미처리 잔량

## 분석 이벤트

- `deck_list_viewed`
- `deck_detail_viewed`
- `deck_code_copied`
- `deck_submit_started`
- `deck_preview_succeeded`
- `deck_draft_created`

P1 대시보드 단계에서 추천, 즐겨찾기, 댓글, 후보 검토 이벤트를 추가한다.

이벤트에는 raw deck code, 이메일, 댓글 본문을 넣지 않는다.

## 제외 범위

공개 베타에서는 야생·변칙, 답글 트리, 실시간 채팅, 개인 카드 컬렉션, 자체
매치 통계, 선수·대회 정규화 DB, AI 가이드 생성을 제외한다.

## 릴리즈 플랜

### Alpha: 현재

- 발견·상세·복사 UI
- 등록·게시와 최근 덱 운영 기반
- 로컬·데모 폴백

### Beta readiness

- 실제 복사 계측
- 추천·즐겨찾기·댓글·신고
- 제품 분석과 오류 추적
- 스테이징 E2E
- 30개 이상 콘텐츠와 운영 런북

### Closed beta

- 20~50명 초대
- 2주간 퍼널·신뢰·콘텐츠 품질 관찰
- 치명적 사용성·데이터 문제 수정

### Public beta

- 검색 유입 페이지 공개
- 수집·신고 운영 당번
- 주간 지표와 가설 리뷰
