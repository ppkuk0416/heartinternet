# Priorities and Development Backlog

## 우선순위 기준

RICE 숫자의 정밀도를 가장하지 않고 다음 순서로 판단한다.

1. 핵심 루프 `발견 -> 판단 -> 복사`의 성공 여부
2. 잘못된 덱·근거로 인한 신뢰 손상 위험
3. 실제 사용자 학습을 얻는 데 필요한 정도
4. 구현·운영 비용과 되돌리기 어려움

- 홈, 목록, 상세, 복사 UI
- 검색·필터·정렬·페이지네이션
- 코드 파싱과 현재 정규전 검증
- 로그인, 등록 4단계, 초안, 수정, 게시
- 출처 근거와 패치 표시
- 최근 덱 수집·검토·연결·트렌딩
- 패치 감지와 승인 전환
- RLS와 핵심 DB 제약
- 실제 복사 이벤트 기록
- 추천·즐겨찾기 토글
- 내 저장 덱 목록과 즉시 저장 해제
- 단일 레벨 댓글, 작성자 삭제, 신고 접수
- 운영자 신고 큐, 기각·검토중·대상 숨김, 감사 로그
- 공식 대회 매니페스트 검증·후보 큐 저장 관리자 UI

출시 전에 남음:

- 실제 Supabase 스테이징 E2E
