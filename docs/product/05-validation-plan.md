종합 평가는 8.1/10이다. 기술 기반은 강하지만 실제 사용자가 쓰는 제품임을
증명하는 사용자 연구, 계측, 커뮤니티 행동과 운영 준비가 부족하다.

## 개선 대책

1. 제품 문서를 저장소 기준으로 고정한다.
2. 핵심 퍼널 이벤트를 대시보드와 운영 의사결정 기준에 연결한다.
3. 공식 대회 매니페스트 관리자 UI를 실제 운영 입력 경로로 고정한다.
4. 실제 Supabase 스테이징에서 인증 포함 E2E를 실행한다.
5. 5명 사용성 테스트와 20~50명 클로즈드 베타로 가설을 검증한다.

## 사용성 테스트 스크립트

대상: 최근 3개월 내 하스스톤 플레이 경험자 5명. 초보·복귀 3명, 숙련 2명.

과업:

1. 현재 패치에서 쉬운 덱을 찾아 복사한다.
2. 선택한 덱의 성적과 출처를 얼마나 믿을 수 있는지 설명한다.
3. 대회 덱을 찾아 원본 출처를 연다.
4. 제공된 덱 코드를 등록해 초안을 저장한다.

질문:

- 덱을 선택할 때 가장 먼저 본 정보는 무엇인가?
- 복사를 망설인 이유는 무엇인가?
- “출처 연결”과 “운영진 확인”의 차이를 어떻게 이해했는가?
- 다음 방문에서 다시 찾고 싶은 정보는 무엇인가?

## 검증 판정

- 과업 성공률 80% 미만이면 공개 베타를 보류한다.
- 신뢰 배지 의미를 3명 이상 오해하면 라벨과 설명을 재설계한다.
- 첫 복사 중앙값이 90초를 넘으면 홈·목록의 정보량과 필터를 축소한다.
- 등록 완료율이 낮으면 필수 가이드 필드와 초안 시점을 조정한다.
