# MVP Scope

## 목표

정규전 유저가 현재 패치 덱을 찾아 신뢰 근거와 운영법을 확인하고 90초 안에
덱 코드를 복사할 수 있는 공개 베타를 출시한다.

## P0: 출시 필수

- 현재 패치 중심 홈과 덱 목록
- 직업, 목적 태그, 출처, 최신성 검색·필터·정렬
- 덱 상세의 요약, 추천 대상, 난이도, 운영법, 멀리건, 약점, 카드 목록
- 한 번의 덱 코드 복사와 성공 피드백
- 덱 코드 파싱, 30장·직업·정규전 유효성 검증
- 이메일 로그인
- 덱 등록, 초안 저장, 수정, 게시
- 출처 유형과 작성자 입력·출처 연결·운영진 확인 구분
- 현재 패치 관리와 이전 패치 경고
- 최근 덱 후보 수집, 중복 제거, 관리자 검토, 공개 덱 연결
- 모바일 핵심 흐름
- RLS, 입력 검증, 기본 레이트 리밋, 운영 감사 기록

## P1: 공개 베타 직후

- 추천 토글
- 즐겨찾기와 내 저장 덱
- 덱별 1단계 댓글과 삭제
- 덱 복사 이벤트 기록
- 기본 신고와 운영자 숨김 처리
- 등록·복사·검색의 제품 분석 이벤트
- 공식 대회 덱 매니페스트 입력 UI
- 빈 상태, 실패 상태, 로그인 복귀 경로 E2E

## P2: 성장 단계

- 기여자 프로필과 신뢰 배지
- 덱 코드 새 버전 발행과 변경 내역
- 댓글 도움됨, 신고 큐, 운영 대시보드
- 랭커·스트리머 허용 소스 어댑터
- 개인 직업·난이도 선호 기반 발견
- 검색어·무결과 분석과 추천 품질 실험
- SEO용 직업·아키타입 랜딩 페이지

## P3: 장기 확장

- 컬렉션·가루 비용 기반 개인 추천
- 매치업·멀리건 통계
- 야생·변칙과 다국어
- 대회 라인업·선수·경기 단위 데이터
- 모바일 앱·게임 보조 기능
- 공개 API와 파트너 피드

## 처음부터 하지 않는 것

- 범용 자유 게시판
- 실시간 채팅
- 덱 시뮬레이터
- 자체 대규모 게임 통계 수집기
- AI가 근거 없이 생성한 승률·가이드
- 모든 지역·모드·언어 동시 지원
- 자동 수집 덱의 무검토 게시

## 1차 출시 기준

다음 조건을 모두 충족할 때 공개 베타 후보로 본다.

1. Supabase가 연결된 실제 환경에서 발견·상세·복사·등록·게시 흐름이 작동한다.
2. 현재 패치의 공개 덱이 최소 30개, 직업 8개 이상에 분포한다.
3. 최소 10개 덱은 출처 연결 또는 운영진 확인 근거를 갖는다.
4. 주요 모바일 뷰포트에서 P0 흐름의 치명적 사용성 문제가 없다.
5. 프로덕션 빌드, 단위·DB·핵심 E2E, 보안 검사가 통과한다.
6. 오류 로깅, 개인정보 안내, 신고·숨김의 최소 운영 절차가 있다.
7. 실제 유저 5명의 과업 테스트에서 4명 이상이 도움 없이 덱을 찾아 복사한다.

현재 저장소는 기술 알파다. 개인정보·이용 규칙과 운영 런북은 준비됐지만 실제
Supabase 스테이징 E2E, 콘텐츠 수량 증거, 외부 오류 추적, 사용자 테스트가 없어
공개 베타 출시 기준은 아직 충족하지 않았다.
